# Cómo arrancar en Build 101

1. Crear un repo PRIVADO nuevo en GitHub HOY (el historial tiene que mostrar que se hizo en el hackathon). Agregar el remoto y hacer push de esta carpeta (ya tiene git y un primer commit) y sumar al equipo como colaboradores.
2. Conectar el repo a Vercel y cargar `ANTHROPIC_API_KEY` (la cuenta de USD 100 del hackathon) en las variables de Vercel.
3. Abrir Claude Code con la cuenta del hackathon en esa carpeta. Primer mensaje:
   > Leé CLAUDE.md y consigna-build101.pdf enteros. Arrancá por H0: Next.js + Tailwind + shadcn, deploy en Vercel y una página que llame a Claude en streaming. Antes de escribir código de la API de Claude, cargá la skill claude-api. Después armá la barra lateral con las secciones de §6.
4. Persona 2, en paralelo: la app de Meta para Business Discovery (§3 de CLAUDE.md).
5. El kit de edición viejo de Paul NO va a este repo: es trabajo previo al hackathon.
